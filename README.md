# portfolio-risk-return-analysis
Цель: провести анализ риска и доходности портфеля ценных бумаг на основе исторических данных, используя ключевые показатели согласносовременной теории портфеля и инструменты языка программирования Python, а затем создать инструмент, способный автоматизировать этот процесс
Задачи:
1. изучить теоретическую базу современной теории портфеля
2. изучить способы расчета ожидаемой доходности портфеля ценных бумаг, а также основных показателей эффективности
3. выявить взаимосвязь между метриками эффективности, определить их роль в анализу риска и доходности
4. разработать код на Python для расчета ключевых показателей эффективности портфеля ценных бумаг
Результат:
Составлен гипотетический портфель инвестора с умеренным риск-профилем, рассчитаны показатели данного портфеля (расчет универсален для расчета портфеля из разных иностранных бумаг)
